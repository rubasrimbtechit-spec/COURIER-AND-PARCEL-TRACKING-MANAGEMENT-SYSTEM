# Spring Boot web application

Main deployable web application. Java 17 / Spring Boot / Maven / Spring JDBC / MySQL. Browser assets are served from `src/main/resources/static`; REST API details are in `API.md`. Set `DB_URL`, `DB_USER`, and `DB_PASSWORD` before starting. From this folder run `mvn test`, `mvn clean package`, or `mvn spring-boot:run`.
